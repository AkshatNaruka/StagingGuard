The Problem

Access Is Not Authority

The agent held the key, so nothing stopped it. Three gaps made the disaster possible, in an unrestricted tool setup.

SCOPE
Agent Exceeds Its Task
Asked to fix staging, it acted on a volume shared with production.
TOKEN
Over-Permissioned Credential
A fully permissioned token turned a guess into an irreversible delete.
NO GATE
Nothing Checks the Call
No check on tool, resource or parameters before execution.

Synthetic baseline: 142,500 fixture records erased. This is not the reported incident’s record count.

The Solution

Enforce Every Action, Not Just the Session

AgntID sits between the agent and its MCP tools and answers three questions on every call: can it see this tool, may it touch this resource, are these parameters safe.

HIDE
Destructive Tools Vanish
Tool surface reduction removes delete_volume. A forced call to the hidden tool also fails.
DENY
Secrets Stay Out
A parameter policy denies .env reads, so credentials never reach the LLM.
STAGING
Writes Stay Scoped
Config changes pass only when env == "staging". Production config writes are denied.
